# Baseline Lab

Desktop app to calculate and compare baselines from `.txt` files already exported
from the instruments (independent of Origin).

The **Rheology** tool fits a flow curve (X = shear rate, Y = shear stress, from a `.txt` or
`.xlsx` file) with the Newton, Bingham, power-law, Herschel-Bulkley and Casson models, plots
them and indicates the one that best describes the sample (lowest AICc).
